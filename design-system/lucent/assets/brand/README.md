# Brand

Mahyar Jaberi's mark: an upright sigma turned a quarter clockwise into an M, with a sigmoid trail in the lockup (a neuron: sum, then activate).

- `mj-mark-ink.svg`, `mj-mark-paper.svg`: the mark alone, single ink: #191918 (ink) or #ffffff (paper).
- `mj-lockup-ink.svg`, `mj-lockup-paper.svg`: the mark with its sigmoid trail. Set the name beside it in the display face, weight 700.
- `mj-app-icon.svg`: favicon and app icon, the paper mark at 62% in an ink squircle.
- `sigma-upright-ink.svg`: the upright sigma, only for telling the story of the mark.

In pages, inline the SVG paths so the mark takes `currentColor` and can animate; these files are for anywhere an image file is needed.
